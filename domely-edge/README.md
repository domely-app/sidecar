# Domely (edge)

A build of the main branch that has not been released. **For a test house only.** It is not
offered as an update to the stable Domely add-on, it has its own data, and it is not promised to
coexist with the stable add-on on one Home Assistant, and running them side by side is untested.
Install one or the other. Pair it as a new home; it does not read the stable add-on's data.
